About Modi

Modi (मोडी) is a cursive script that was used to write Marathi for several centuries, for revenue records, court papers, letters and accounts across Maharashtra, until Devanagari replaced it in the twentieth century. Writers kept the pen on the paper, so letters hang from a continuous headline and run into each other.

Large archives are still written in Modi and few people can read them, which is why character recognition is useful here.

About these labels

Class names come from the dataset’s romanised folder names. The Devanagari shown beside them was matched by hand against the Unicode Modi chart and has not yet been checked by a Modi reader. A few names (for example the dental and retroflex consonants) are easy to mix up, so please treat them as provisional.
